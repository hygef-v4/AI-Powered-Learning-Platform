# Privacy Policy — AI-Powered Learning Platform

_Last updated: 2026-11-15_

AI-Powered Learning Platform ("the platform") is a university course project used internally for teaching and learning.

## Google Drive access

The platform's Google integration requests only the `drive.file` scope. This means it can
see, create and manage **only the files and folders that the platform itself creates** in the
connected Google account's My Drive (an "AI Learning Platform" folder holding uploaded course
materials, document images and encrypted database backups). It cannot read any other files in
the account.

## What we store

- Files that users upload to the platform (course materials, document images), stored in the
  connected Google Drive account or on the server's local storage.
- Account information needed to run the platform (name, school email, role, student code) and
  learning data (assignments, submissions, grades), stored in the platform's own database.

## What we do not do

- We do not sell or share user data with third parties.
- We do not use Google user data for advertising or profiling.
- Google credentials (OAuth client and refresh token) are kept in server configuration and are
  never exposed to end users.
