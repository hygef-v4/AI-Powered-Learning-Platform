# Teacher-scored grading pilot

No teacher reference grades or real student submissions are present. Do not invent reference scores or report a model-quality pass from synthetic validator fixtures.

See [the quality guide](../../../../../docs/guides/mcp-grading-quality.md) for the proposed 20-case pilot and metrics. Add authorized, de-identified cases only after teachers supply item-level reference scores and agree acceptance thresholds. Record rubric/context/model/policy versions. The deterministic regression tests remain in the grading service test package.
