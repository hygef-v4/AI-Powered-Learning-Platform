# U04/U13/U14 verification

[Scope and commit plan](../plans/code-generation-plan/2026-11-02-u04-u13-u14.md). Source baseline: `d33e31c3`; branch `fix/u04-u13-u14`.

## Functional changes

U13 previously rejected any URL containing list/index, including links identifying a single video. Both validators now accept that video and the backend saves its canonical URL. Playlist-only and unsafe/ambiguous URLs remain rejected.

U14 previously hid settings and rejected preference APIs for non-Student roles. Settings now use the current principal's role on both UI and backend:

| Role | Email preferences | Default |
|---|---|---|
| Student | Enrollment, assignment opened, grade published, deadline reminder, important class announcement | Existing five enabled |
| Teacher | Leader-change request, question-review result | Disabled until enabled |
| Subject Manager | Teacher preferences plus question proposal | Disabled until enabled |
| Admin | Backup failure | Required, enabled and locked |

Preferences affect newly scheduled email, as before. Pending/deferred email is not rechecked at send time. Delivery still verifies active account and current role. No new in-app recipients, schema, dependency or external provider calls were added.
