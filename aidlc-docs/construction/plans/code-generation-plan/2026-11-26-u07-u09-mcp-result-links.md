# U07/U09 — Mở kết quả MCP trên web

1. [x] Mở đề theo đề xuất được chỉ định trong link. Đề xuất hợp lệ, đúng phiên bản được đưa vào bản nháp. Đề xuất cần xem lại hiển thị trong hộp duyệt.
2. [x] Kiểm tra phiên bản gốc khi áp dụng đề xuất soạn đề MCP. Mở lại link đã xử lý hiển thị bản nháp hiện tại.
3. [x] Dùng cơ chế AI web để điền điểm và nhận xét từ đề xuất chấm được chỉ định. Giữ form đang sửa và thao tác lưu, công bố của giảng viên.
4. [x] Cập nhật hướng dẫn MCP về cách mở link.
5. [x] Kiểm tra link, đề xuất cũ, link mở lại và hành vi chưa lưu điểm.
