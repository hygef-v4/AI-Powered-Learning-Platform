## Review focus, acceptance and limits

1. Optional requests may settle before primary data or after a later refresh/denial: Task 1 tests both ordering directions and cancellation.
2. Only one source may hang while others succeed: Task 1 tests loading, timeout and continued usability without waiting for the 30-second refresh.
3. Removed learners, superseded receipts and group overrides must not leak wrong grades: Task 2 covers selection and scope; existing backend regressions protect grade locks/resubmission.
4. Wire image IDs and typed table/diagram content must survive adaptation without mutation: Task 3 tests block kinds and read-only rendering.
5. Legacy checkbox/null-map/rounding behavior must survive scoring/helper moves: Tasks 4/5 retain characterization and existing error codes/copy.

Done means all six findings are addressed, applicable automated checks pass, evidence/limits are recorded and no unrelated behavior changed. The student lookup still may load class-wide source metadata once; this plan does not promise database-level per-student pagination, streaming export, load-test latency or AI grading-quality calibration. No large folder reorganization is included.
