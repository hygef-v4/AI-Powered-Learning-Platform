Hướng dẫn lấy khóa API
Gemini
  1. Mở Google AI Studio, đăng nhập tài khoản Google.
  2. Chọn "Get API key" → "Create API key".
  3. Dán khóa vào đây và bấm Kiểm tra.
OpenAI
  1. Mở platform.openai.com → API keys.
  2. Bấm "Create new secret key", đặt tên.
  3. Nạp tiền cho tài khoản trước khi dùng.
Claude
  1. Mở console.anthropic.com → API Keys.
  2. Bấm "Create Key", chọn workspace.
  3. Thiết lập hạn mức chi tiêu trong Billing.
