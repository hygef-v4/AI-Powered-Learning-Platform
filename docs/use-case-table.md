# 4.2 Use Cases (UC)

> Review draft: names and IDs in this table have not yet been synchronized to other documents.

This table contains 33 active MVP use cases, numbered consecutively from 1 to 33. A subject manager can add YouTube sources to subject materials; a teacher can add them to class content. Simulation Exam is outside the MVP.

| ID | Use Case | Feature | Use Case Description |
|---|---|---|---|
| 1 | Activate Account | Authentication | Lets a user request activation for a school-issued account using a school email, verify an emailed OTP and set a password. The user can request another OTP within the rate limit; responses do not reveal whether an account exists. |
| 2 | Sign In | Authentication | Lets a user sign in with the school email and password, with account status checks, attempt limits and safe error messages. |
| 3 | Sign Out | Authentication | Lets a signed-in user end the current session and revoke the related credentials. |
| 4 | Recover Password | Authentication | Lets a user request a password reset, verify an OTP and set a new password without revealing whether the account exists. |
| 5 | Manage Profile | Profile Management | Lets a signed-in user view their own profile, update permitted fields, upload an avatar and change the password after verifying the current one, but not change their identifying email or role. |
| 6 | Manage Accounts | Account Management | Lets the administrator browse accounts by role or status; create one school-issued account in PENDING without setting its password or sending email; import school-issued accounts from a file into PENDING with a preview and per-row success or error results and no email sent; and update account information, highest role and active status with privilege checks, without deleting history. Temporary sign-in restrictions remain with LoginThrottle. |
| 7 | Manage Subjects | Subject Management | Lets the administrator view subjects with their details, manager and classes; create a subject with a valid code; update its information without losing history; and assign an account with a suitable role as its subject manager. |
| 8 | Manage Classes | Class Management | Lets an authorized user view the class list and class details within the assigned scope; the administrator creates a class under exactly one subject and assigns or changes its one primary teacher; the administrator or assigned teacher updates class information and opens or archives the class while keeping content and learning history. |
| 9 | Manage Enrollment | Enrollment | Lets the class manager view current or past enrollments, enroll a student only once with a notification, and remove access while keeping learning history. Lets a student self-enroll into an open class with a valid invite code, with attempt limits and no class information disclosed for an invalid code; the teacher can regenerate the code. |
| 10 | Manage Subject Materials | Subject Content | Lets the subject manager view, upload, update, archive and index learning materials of an assigned subject for RAG. This includes adding a YouTube video or playlist, using existing captions without transcribing audio, and tracking timestamped transcript processing within the subject scope. |
| 11 | Manage Class Content | Class Content | Lets the teacher view, create, upload, update, reorder, archive and publish valid content to enrolled students in an assigned class. This includes reusing a subject lesson, adding a YouTube video or playlist as a lesson RAG source, using existing captions without transcribing audio, and tracking timestamped transcript processing within the class scope. |
| 12 | Access Enrolled Class | Learning Dashboard | Lets the student open an enrolled class with its content, assignments and groups within the permitted scope. |
| 13 | Access Lesson | Learning Content | Lets an enrolled student open published content and download the permitted files. |
| 14 | Post and Discuss Class Announcements | Class Communication | Lets the teacher post announcements to an assigned class and lets class members post questions and replies within the scope of their class. |
| 15 | Manage Groups and Leaders | Group Management | Lets an authorized user view groups, leaders, members and contribution status in a class; the teacher creates or updates groups, splits a class randomly, reuses groups from another assignment, adds or removes members and appoints exactly one leader; a member submits a leader-change request with a reason and a proposed leader, and the teacher approves or rejects it and notifies the decision. |
| 16 | Manage Question and Rubric Bank | Question Bank | Lets an authorized user view, create, update, clone, import, archive, version and preview questions and rubrics within the permitted scope. |
| 17 | Manage Assignments | Assignment Management | Lets an authorized user view assignments and their details within the assigned scope, and create one in GRADED or PRACTICE mode in a single editor: Text Essay with instructions and limits; multiple-choice quiz with questions, answer keys and scoring rules; Diagram Essay with the DOCUMENT editor, an outline, optional DOCX import and embedded Draw.io diagrams with XML validation; Code Lab with the coding problem, language, quota, test cases and a sandbox run of the sample solution; or a group document assignment whose section outline is defined here. A rubric is attached in every type. The same use case covers previewing and approving, publishing to an assigned class with a schedule and attempt limits, editing or retiring a publication, and cloning, versioning, comparing versions, retiring or copying an assignment with its rubric to another class the teacher teaches, without copying schedules, attempts, submissions or grades. |
| 18 | Manage Subject Templates | Assignment Template | Lets the subject manager create, publish, version or withdraw a subject template, including PRACTICE or GRADED quizzes, and a teacher copy a released template into an independent class draft. |
| 19 | Create Assignment with AI | AI Creation | Lets the teacher ask the AI service to create an assignment or question draft from class content, review the sources, edit, accept or discard the result before publishing. |
| 20 | Create Template with AI | AI Creation | Lets the subject manager ask the AI service to create a subject-level template or question draft grounded in subject RAG, review its sources, edit, accept or discard the result. |
| 21 | Manage AI Service | AI Administration | Lets the administrator view AI usage, quota and cost, configure the allowed model and enable or disable the AI service. |
| 22 | Do Text Essay | Assignment Workspace | Lets the student open assigned work with its requirements, rubric, deadline and remaining attempts, start an attempt, write and autosave an open-ended answer, submit it and read the submission receipt, and review submitted attempts. For a PRACTICE attempt the receipt also shows one AI score and feedback when enough credits are available; without enough credits the attempt is submitted without an AI score and the student must submit a new attempt after buying credits. Practice results stay outside the official gradebook. |
| 23 | Do Multiple-Choice Quiz | Assignment Workspace | Lets the student open assigned work with its requirements, deadline and remaining attempts, start an attempt, answer and autosave a quiz, submit it and read the submission receipt, and review submitted attempts. Closed questions are auto-scored against the answer-key version; PRACTICE results stay outside the official gradebook. |
| 24 | Do Diagram Essay | Diagram Assignment | Lets the student open assigned work with its requirements, rubric, deadline and remaining attempts, start an attempt, write a document, preview and import DOCX into the active attempt, draw on the embedded Draw.io canvas, save a draft, submit it with the full Draw.io XML and read the submission receipt, and review submitted attempts. For a PRACTICE attempt the receipt also shows one AI score and feedback when enough credits are available; without enough credits the attempt is submitted without an AI score. Practice results stay outside the official gradebook. |
| 25 | Do Code Lab | Code Assignment | Lets the student open assigned work with its requirements, deadline and remaining attempts, start an attempt, write code, run it in the sandbox, autosave and submit the source within the assignment limits, read the submission receipt and review submitted attempts. |
| 26 | Do Group Document | Group Submission | Lets group members claim a section defined in the assignment, work on it, mark it done and watch the shared document update, and lets the teacher or leader release a claimed section. The leader submits the document; the system submits the current document automatically when the deadline passes. |
| 27 | Grade Submissions | Grading | Lets the teacher view submission status of an assigned class with automatic reminders 24 hours before the deadline, open GRADED submissions with the student work, rubric, attempts and auto-scored results, enter the score and feedback with a reason for any override, grade a submitted group document by reviewing each member's contribution and assessing integration and consistency, finalize many valid scores at once after an eligibility check, and publish scores and feedback to the right students. PRACTICE work stays outside this queue. |
| 28 | Grade with AI Assistance | AI-Assisted Grading | Lets the teacher request, review, accept or override an AI grading proposal with a reason, for an individual submission or a group document; the AI never decides the final score. |
| 29 | View Grades | Gradebook | Lets the student view their own published final score and feedback. |
| 30 | View and Export Gradebook | Gradebook | Lets an authorized user view the gradebook together with the change history, actor, timestamp and reason, and export a CSV or XLSX gradebook for a class or assignment containing only data within their permitted scope. |
| 31 | Buy AI Credits | Payment | Lets an ACTIVE Student, Teacher, Subject Manager or Administrator view AI credit packages, pay and track payment status. The administrator also creates, edits and hides packages. Verified PayOS payment grants purchased credits exactly once. Student credit use is limited to Practice Text/Diagram Essay grading. |
| 32 | View Notifications | Notification | Lets a user receive, read and configure notifications about class posts and Q&A, assignments, deadlines, groups, grades and payments within their scope. |
| 33 | View Audit Log | Audit | Lets an authorized administrator view audit events by actor, action, object, result and time; audit records cannot be edited or deleted. |
